# Prose patterns

Detect, then rewrite. Preserve meaning and tone.

## Content

- Puffery ("pivotal", "testament to", "evolving landscape"): state what
  happened instead.
- Vague attributions ("experts believe", "reports suggest"): name the
  source or delete the claim.
- Superficial participles ("highlighting…", "showcasing…", "ensuring…"):
  delete, or expand into a sentence with a real subject.
- Formulaic arcs ("despite challenges… continues to thrive"): replace with
  the specific fact.

## Language

- Stock AI vocabulary (delve, crucial, foster, garner, intricate, pivotal,
  tapestry, testament, underscore, vibrant, landscape-as-abstraction):
  plain words.
- Fancy copulas ("serves as", "stands as", "boasts"): "is" or "has".
- "Not just X, but Y": state the point.
- Forced triads: use the natural number of items.
- Synonym cycling for one referent: pick one name and repeat it.
- Abstract metaphor nouns (substrate, nexus, flywheel, north star,
  paradigm): the concrete word.

## Style

- Em dashes: banned outright, not just as crutches. End the sentence or
  use a comma. Parentheses as a dash substitute trade one tell for
  another. Sole exception: an image's alt text may keep one when the
  house banner format uses it.
- Colon connectors as crutches: end the sentence.
- Long sentences: a sentence stacking three or more clauses gets split.
  If reading it aloud needs a breath, it is two sentences.
- Bold-label lists that restate the line ("**Performance:** performance
  improved"): prose.
- Title Case headings → sentence case; decorative emoji → gone; curly
  quotes → straight.

## Voice

- Say what it does, not how it feels: name the mechanism or the number. If
  the sentence could sit unchanged in another project's docs, it says
  nothing; cut it.
- Vary rhythm; one idea per sentence; active voice with a named actor.
- Cut adverbs or replace verb+adverb with the stronger verb or the
  measured delta.
- Have opinions where the document's job allows them; first person is
  fine.

## Artifacts

- Chatbot phrases ("Hope this helps!", "Great question!"), cutoff
  disclaimers, and sycophancy: delete.
- Hedging stacks ("could potentially possibly"): one honest qualifier.
- Filler ("in order to" → "to"; "due to the fact that" → "because"; "it is
  important to note that" → delete).
- Generic conclusions ("the future looks bright"): specific plans or end.
- Verbose UI copy and the docs that narrate it: "Click the button below
  to get started with creating your first project" is "Create a project".
  Labels, empty states, and tooltips carry the action, not a tour; docs
  that restate what the interface already shows get deleted.
