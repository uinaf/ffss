### ffss skills

Use an ffss skill when the task enters its lane; skip them for questions,
lookups, and small edits that ship without a change request. Name the skill
when delegating.

- Open or update a change request: `slopcourier`.
- Review feedback, CI, or merge on an open one: `slopnanny`.
- Independent review when asked, or without review bots or required reviews:
  `slopguard`.
- Run an agreed plan end to end: `slopmachine`.
- Docs or agent guidance drifted from sources: `slopscriber`.
- Record future work in the tracker: `slopspec`.
- Missing stack skills: `slopskills`. Repository readiness: ask the user to
  invoke `slopprep`.
- Remove AI tells when asked: `slopclean`.
