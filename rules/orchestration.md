## Orchestrating agents

- Keep coupled work in this loop. Delegate only work that needs little from
  this session and returns a compact result: independent research, a
  component behind a clean interface, or black-box verification.
- Validate a delegate's diff, checks, and public text before merging or
  posting. Out-of-scope findings get a reply or a tracker item.
- Wait for delegates to report; poll only external state that reports to
  nobody, with a deadline and a failure exit.
- A brief gives the goal, scope, authority, constraints, and what to report
  back, and names the skill that owns each artifact. That skill and the
  repository's template write the artifact's text.
- A review or verification brief gives the artifact and checkable pass
  criteria. It leaves out your conclusion and the build history.
- Run delegates in parallel only on separate files or separate worktrees.
- Cap fix-and-review rounds at three. After the third, reconsider the
  approach and say so.
- Delegates return proof detail, commands, and review findings to you.
- Every brief, follow-ups included, repeats the limits the user or task set:
  forbidden credentials, shared devices, actions that need the user. Beyond
  those, the delegate may use every tool and credential the session can.
